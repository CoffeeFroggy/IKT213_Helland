# Visual Defect Inspector

Dette er sluttleveringen vår i IKT213. Programmet sjekker form, mål,
skraper og sprekker på skjermbeskyttere.

## Slik kjører du programmet

Pakk ut `VDI_Final_Code.zip` på Windows. Følg installasjons- og
oppstartsguiden i `VDI_Windows_For_Teammate_NEW/VDI_Live_Inspection/README.md`. Koble til kameraet, legg en beskytter
i Blackbox og trykk **Run System Analysis**. Resultatet vises i
programmet og lagres i historikken.

## Datasett

Bildene vi brukte til trening ligger i `dataset ikt213 final.zip`
i [sluttleveringen](https://github.com/CoffeeFroggy/IKT213_Helland/releases/tag/vdi-final).
