# Visual Defect Inspector – IKT213

Dette er Windows-versjonen vi brukte på demonstrasjonen. For å
gjennomføre en inspeksjon trenger programmet den fysiske
Blackbox-riggen med kameraet og lysoppsettet vårt.

Studentassistentene og foreleseren så prosjektet i bruk på
demonstrasjonen. Vi leverer koden som dokumentasjon av versjonen
vi viste. Datasettet inneholder bildene vi brukte til å trene modellen.
